# Angličtina – procvičování

Interaktivní webová aplikace pro učení angličtiny pro české uživatele.

**Ukázka online:** https://kamilhradek.github.io/anglictina/ (po zapnutí GitHub Pages)

## Funkce
- výběr úrovně A1–C2 (zapamatuje se v prohlížeči, lze kdykoli změnit)
- slovní zásoba s kartičkami (anglicky ↔ česky)
- kvíz s výběrem odpovědi a okamžitou zpětnou vazbou
- doplňování slov do vět
- skóre a statistiky úspěšnosti
- česky ovládané, responzivní, ovladatelné klávesnicí

## Spuštění
Stačí otevřít `index.html` v prohlížeči. Aplikace nemá žádné závislosti ani build krok.

## Rozvoj
Struktura projektu a konvence jsou v [CLAUDE.md](CLAUDE.md). Nová slovíčka a věty se přidávají v objektu `LEVELS` v `index.html`.
